# v0.1 results — deterministic golden-standard behavior

This document records the current v0.1 model behavior. The numbers are not yet
fit to a specific human macrophage dataset (that is v0.2), but the qualitative
rules are literature-grounded and tests verify the expected direction of change.

## Golden experiments

### LPS → M1

Run:

```bash
python experiments/lps_response.py
```

Observed at 60 ticks:

- NF-κB = 1.0, IRF3 = 0.7
- polarization score = +0.337 (`M1`)
- metabolism = `glycolysis`
- morphology = `spread`
- cumulative cytokines: TNF-α 8.885, IL-6 7.108, IL-1β 5.331; IL-10/TGF-β 0

Interpretation: LPS/TLR4 activates NF-κB and drives a classical inflammatory
profile, matching Mosser & Edwards (2008) and O'Neill et al. (2016).

### IL-4 → M2a + autocrine IL-10/STAT3 loop

Run:

```bash
python experiments/il4_response.py
```

Observed at 60 ticks:

- STAT6 = 0.996
- STAT3 = 0.765 (emergent: IL-4 drives IL-10 secretion, IL-10 activates IL-10R/STAT3)
- polarization score = -0.598 (`M2`)
- metabolism = `oxphos`
- cumulative cytokines: IL-10 8.886, TGF-β 5.924; TNF-α/IL-6/IL-1β 0

A dedicated test (`test_stat3_under_il4_is_autocrine_il10_driven`) blocks IL-10
sensing and verifies STAT3 disappears. This proves the STAT3 behavior is caused
by the autocrine loop, not an artifact.

### Phagocytosis + ROS

Run:

```bash
python experiments/phagocytosis.py
```

Observed:

- 5/5 IgG-opsonized particles are engulfed
- ROS burst triggered and decays
- unknown ligand-class particles are not engulfed (anti-fabrication / no invented receptor mapping)

### CCL2 chemotaxis

Run:

```bash
python experiments/chemotaxis.py
```

Observed over 20 seeds × 200 ticks:

- with +x CCL2 gradient: mean Δx = +39.18 µm
- no gradient: mean Δx = -2.91 µm

Interpretation: biased random walk now shows a clear directional drift.

## Dose-response

Run:

```bash
python experiments/dose_response.py
```

Key values:

| LPS (ng/mL) | polarization | NF-κB | TNF-α cumulative |
|---:|---:|---:|---:|
| 0.001 | +0.000 | 0.000 | 0.00 |
| 0.05 | +0.010 | 0.031 | 0.58 |
| 0.5 | +0.169 | 0.500 | 9.51 |
| 3.0 | +0.316 | 0.936 | 17.80 |
| 10.0 | +0.334 | 0.989 | 18.80 |
| 100.0 | +0.337 | 1.000 | 19.01 |

Interpretation: sigmoidal LPS/TLR4 response centered near the TLR4 Kd (0.5
ng/mL), saturating by ~10 ng/mL. This is qualitatively correct; quantitative
calibration to human MDM / THP-1 / RAW264.7 dose-response curves is v0.2.
